CodeBud firmware flasher

Flash the CodeBud boot sketch to your ESP32 directly from Chrome or Edge - no PlatformIO or VS Code required.

Voordat je begint:
  • Gebruik Google Chrome of Microsoft Edge (Web Serial API vereist).
  • Sluit je ESP32 via USB aan (data-kabel, niet alleen lader).
  • Klik hieronder op "Connect", kies de juiste seriële poort, en klik daarna op "Install".
Je browser ondersteunt Web Serial niet. Gebruik Chrome of Edge op desktop. Web Serial is alleen beschikbaar via HTTPS of localhost.

Na het flashen zou het scherm zwart moeten worden en "CodeBud booted" moeten tonen.
